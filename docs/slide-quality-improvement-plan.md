# スライド品質・視覚バランス・メッセージ性 総合改善計画

本ドキュメントは、AIが生成するMarpプレゼンテーションスライドにおける「不自然な配置・画像サイズ（スカスカ感・バランス崩壊）」および「濃淡のない『で、何？』なスライド」を根本から撲滅するための総合改善計画書です。チェックボックスを用いて各タスクの進捗を管理します。

---

## 1. 課題の整理と分析

ユーザーから提供されたスライド画像（5枚）より、以下の根本課題が特定されました。

| 対象 | 発生している問題 | 根本原因 |
| :--- | :--- | :--- |
| **スライド1**<br>(Museの本質) | 4要素しかない概念図が中央に小さくポツンと配置され、上下左右に巨大な死に領域が発生。下部の主張テキストと図が分裂。 | 低密度（要素数が少ない）な概念図をSVG単体で全画面中央に置いている。CSS Native（stepsや3カラムカード）や2段構成（図＋具体例）を選択していない。 |
| **スライド2**<br>(Spark・Image・Video) | 左カラムに巨大な「1M」が唐突に配置され、右カラムは薄いテキストが2つ並ぶだけで、左右の高さと視覚的重みが不揃い。 | `cols-2` で左右の重み・バランスを考慮するプロンプト制約・Linterチェックが存在しない。全体像（推論モデルSparkが司令塔であること）の図解がない。 |
| **スライド3**<br>(旅行支度API) | 4つの箱を横一列に並べたフローチャートが中央にあるだけで、画面の縦60%以上が空白。具体性（雨具提案のAPI入出力）が皆無。 | 横長1行フローを全幅スライドに単体配置している。APIの具体例なのに「入力・条件・出力」の具体的データが欠落し、抽象論の箱だけでスライドを浪費している。 |
| **スライド4**<br>(素材の編集・合成) | 2カラムに薄い箇条書きが置かれているだけ。画像トピックなのにビジュアルや対比がなく、余白の使い方が不自然。 | 「従来（テキスト一発生成） vs 今回（複数素材の合成・対話修正）」の対比（Before/After）がなく、文字だけのフラットな要約になっている。 |
| **スライド5**<br>(TEXT+IMAGE → VIDEO+AUDIO) | 見出しや矢印、バッジを適当に縦積みしただけで、フォントサイズ差が激しく、チープで中途半端なメッセージスライドになっている。 | `key-message` クラスの誤用（本来は `> 引用文` で1つの短文をガツンと見せる専用）。対比や進化を表現するコンポーネントが不足している。 |

## 2. 改善方針（4つの柱）

1. **コンテンツ設計の強化（「So What?」3層構造の徹底）**:
   - すべてのスライドに「主張（Conclusion）」「対比・構造（Contrast/Structure）」「具体的ファクト・例（Evidence/Proof）」を義務付け。
   - 単なる機能の要約や抽象的な矢印フローを禁止。
2. **レイアウト＆ビジュアルバランスの刷新**:
   - 低密度図（4要素以下）のSVG単体配置を禁止し、「CSS Native（steps / cols-3）」または「ハイブリッド2段構成（ミニ図 ＋ 具体例カード）」を推奨。
   - `cols-2` における左右の視覚的対称性（Visual Balance）の制約を明文化。
   - `key-message` の用途制限（短文1行専用）と、対比レイアウト（Before/Afterカード）の新設。
3. **自動検知・品質ゲートの強化（スクリプト改修）**:
   - `marp-lint.py`:
     - `SPARSE_DIAGRAM_SLIDE`: 小さな図と僅かなテキストで画面がスカスカになるのを検知。
     - `MISUSED_KEY_MESSAGE`: `key-message` 内で複数の見出しやリスト、バッジの混在を検知。
     - `UNBALANCED_COLUMNS`: 2カラムでの極端な情報量・行数の偏りを検知。
   - `marp-dom-extractor.py`:
     - `SPARSE_CONTENT`: 垂直方向のコンテンツ占有率（Fill Ratio）が低すぎるスライドを自動検知。
4. **AI Visual Inspection（画像フィードバックループ）のプロンプト強化**:
   - 生成画像の目視確認時に「スカスカ感・孤立した極小図・情報の濃淡」を必ず判定するチェックリストを追加。

## 4. 完了条件（Definition of Done）

1. スライド内に「ポツンと浮いた極小の図」や「上下左右の無駄な巨大空白」が完全に発生しなくなること。
2. スライドをパッと見ただけで、「何が言いたいのか（結論）」「何が従来と違うのか（対比）」「具体的な根拠やデータ（具体）」が3秒以内に伝わる濃淡があること。
3. `marp-lint.py` および DOM診断により、スカスカ・アンバランス・クラス誤用が自動検知されること。
4. 提示された5枚のスライドの改善サンプルが完成し、圧倒的なクオリティ向上が実証されていること。
