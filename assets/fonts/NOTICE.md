# Bundled Fonts

Self-hosted open fonts used by the slide themes via `@font-face`. Bundling them
keeps rendering identical across machines and lets exported HTML/PDF embed the
exact same type. Every `.ttf` here is referenced by at least one theme (see the
per-theme sections below).

## warm-sunnyday

- `Poppins-Bold.ttf`, `Poppins-Regular.ttf`, `Poppins-Italic.ttf`, `Poppins-BoldItalic.ttf` — Latin body text
- `ZenMaruGothic-Bold.ttf`, `ZenMaruGothic-Medium.ttf`, `ZenMaruGothic-Regular.ttf` — Japanese body text
- `JetBrainsMono-Regular.ttf`, `JetBrainsMono-Bold.ttf`, `JetBrainsMono-Italic.ttf`, `JetBrainsMono-BoldItalic.ttf` — code blocks

## prism-edge

- `SpaceGrotesk-Bold.ttf`, `SpaceGrotesk-Medium.ttf`, `SpaceGrotesk-Regular.ttf` — Latin body text
- `NotoSansJP-Variable.ttf` — Japanese body text (variable font)
- `JetBrainsMono-Regular.ttf`, `JetBrainsMono-Bold.ttf`, `JetBrainsMono-Italic.ttf`, `JetBrainsMono-BoldItalic.ttf` — code blocks

## slate-minimal

- `Caladea-Regular.ttf`, `Caladea-Bold.ttf`, `Caladea-Italic.ttf`, `Caladea-BoldItalic.ttf` — serif body text
- `Poppins-Bold.ttf`, `Poppins-Regular.ttf`, `Poppins-Italic.ttf`, `Poppins-BoldItalic.ttf` — sans-serif headings
- `NotoSansJP-Variable.ttf` — Japanese body text (variable font)

## nebula-glass

- `Poppins-Bold.ttf`, `Poppins-Regular.ttf`, `Poppins-Italic.ttf`, `Poppins-BoldItalic.ttf` — Latin body text
- `NotoSansJP-Variable.ttf` — Japanese body text (variable font)
- `JetBrainsMono-Regular.ttf`, `JetBrainsMono-Bold.ttf`, `JetBrainsMono-Italic.ttf`, `JetBrainsMono-BoldItalic.ttf` — code blocks

## azure-clarity / crimson-clarity

No bundled fonts. Both use the OS font stack
(`Segoe UI` / `Hiragino Sans` / `Yu Gothic` / `Meiryo`, `Consolas` / `Monaco`),
so they need nothing downloaded.
