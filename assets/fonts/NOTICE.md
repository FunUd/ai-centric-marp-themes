# Bundled Fonts

This directory bundles open fonts used by the slide themes.

## warm-sunnyday

- `Poppins` — Latin body text
- `Zen Maru Gothic` — Japanese body text
- `JetBrains Mono` — code blocks

## prism-edge

- `Space Grotesk` — Latin body text
- `Noto Sans JP` — Japanese body text (variable font)
- `JetBrains Mono` — code blocks

## Upstream projects

- Poppins: https://github.com/itfoundry/Poppins
- Zen Maru Gothic: https://github.com/googlefonts/zen-marugothic
- Space Grotesk: https://github.com/floriankarsten/space-grotesk
- Noto Sans JP: https://github.com/notofonts/noto-cjk
- JetBrains Mono: https://github.com/JetBrains/JetBrainsMono
