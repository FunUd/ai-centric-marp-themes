# Design Philosophy

Nebula Glass focuses on the balance between **Space** and **Light**.

### Key Principles
1. **Transparency**: Using glass panels to create hierarchy without clutter.
2. **Atmosphere**: Deep backgrounds with vibrant color shifts.
3. **Clarity**: High-contrast typography for readability.
