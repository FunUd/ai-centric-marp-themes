# デザイン哲学

Nebula Glassは、**「空間」** と **「光」** の調和に焦点を当てています。

### 3つの核となる原則
1. **透明性**: ガラスパネルによる情報の階層化
2. **空気感**: メッシュグラデーションによる動的な背景
3. **明瞭性**: 高コントラストなタイポグラフィによる可読性

# 導入ステップ

1. Markdownのフロントマターで `theme: nebula-glass` を選択します。
2. `cover-nebula` を使用して、洗練された印象で開始します。
3. `glass-card-layout` で、最も重要なメッセージを強調します。
4. `split-glass` を活用し、テキストと視覚要素のバランスを整えます。
